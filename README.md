# Heat equation on the sphere with icosahedral meshes

Code, experiment scripts, figures, and numerical data accompanying the article
**"Numerical solution of the heat equation on the sphere with icosahedral
meshes: mixed finite volume formulation, Crank–Nicolson scheme, and
convergence verification"** by Fábio Freitas Ferreira (Universidade Federal
Fluminense, UFF).

The work revisits and extends the author's 2008 PhD dissertation (Instituto
Politécnico, Universidade do Estado do Rio de Janeiro — IPRJ/UERJ), supervised
by the late Prof. Francisco Duarte Moura Neto, and two accompanying conference
papers. It discretizes the heat and Poisson equations on the sphere with a
mixed potential-flux finite volume method over an icosahedral mesh and its
dual (Voronoi-type) mesh.

## Repository contents

- `code/` — Python/NumPy/SciPy reimplementation: icosahedral mesh generation
  and refinement (`icosphere.py`), the finite-volume heat solver
  (`heat_solver.py`), the Poisson solver and local iterative algorithm
  (`heat_iterative.py`, `poisson_iterative.py`), and the scripts that run
  every numerical experiment reported in the article (`run_*.py`,
  `plot_mesh*.py`). Each experiment script has an `_en` counterpart that
  reproduces the same computation with English-language figure labels.
- `figures/` and `figures_en/` — all figures used in the article (Portuguese-
  and English-labelled versions), generated by the scripts in `code/`.
- `notes/data/` and `notes/data_en/` — CSV files with the raw numerical
  output of every convergence study, case study, and parameter sweep in the
  article (Portuguese- and English-header versions).
- `latex/` — LaTeX source of the original Portuguese-language article.
- `latex_en/` — LaTeX source of the English-language translation submitted
  for journal publication.

## Reproducing the results

```bash
pip install -r requirements.txt
cd code
python run_convergence_study.py     # spatial/temporal convergence, exact solution
python run_case_studies.py          # Cases 1-2 (conservation, source term)
python run_case3_steady.py          # Case 3 (harmonic source, steady state)
python run_case4_imprinting.py      # Case 4 (grid imprinting near pentagons)
python run_beta_sweep.py            # Poisson relaxation-parameter beta sweep
python run_beta_sweep_heat.py       # heat-equation beta sweep
python plot_mesh.py                 # mesh/dual-mesh illustration figures
```

Each script writes its figures to `../figures/` and its numerical data to
`../notes/data/`. Append `_en` to any script name to reproduce the
English-labelled counterpart (writing to `../figures_en/` and
`../notes/data_en/`).
